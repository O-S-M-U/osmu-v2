# Worker D 교정 재배정 결정

- 결정일: 2026-09-21
- 승인자: Project owner
- 관련 작업: `0.1B`, `0.1B-R1`

## 배경

Worker C가 연락 두절되어 추가 설명이나 수정 수행을 기대할 수 없고, owner는 버전 변경·결정 절차를 Worker D가 독립적으로 다시 수행하도록 요청했다.

## 결정

1. Worker C의 활성 배정을 종료하고 상태를 `unavailable`로 기록한다.
2. 기존 `0.1B`, branch, PR #4, commit과 evidence는 삭제하거나 작성자를 변경하지 않는다.
3. Worker D를 별도 에이전트 인스턴스로 등록하고 교정 작업 `0.1B-R1`을 배정한다.
4. `0.1B-R1`은 기존 결과를 복사하는 작업이 아니라 원래 계약에서 독립적으로 절차를 도출하고 현재 main과 비교하는 작업이다.
5. `0.2`는 `0.1B-R1`이 verified/done이 될 때까지 시작하지 않는다.

## 영향

- 제품 명세나 고정 baseline 자체는 변경하지 않는다.
- `0.1B`의 과거 완료 이력은 감사 기록으로 유지한다.
- D의 결과가 verified되고 main에서 재검증되면 후속 작업은 그 결과를 사용한다.
