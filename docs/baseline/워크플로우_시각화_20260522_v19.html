1순위 — 저품질 반복 평가 키워드
삭제 조건 (AND)
evaluation_count ≥ pool_eviction_eval_count (3)
avg_score < pool_eviction_score_threshold (45)
정렬
last_evaluated_at 오래된 순 (ASC)
집계 방식
evaluation_count, avg_score는 keyword_evaluations 테이블에서 실시간 COUNT / AVG 집계. 별도 컬럼 불필요.
2순위 fallback — 1순위 후보 부족 시
적용 조건
1순위만으로 초과분을 채우지 못했을 때
정렬
① last_evaluated_at 오래된 순 (ASC)
② 동점 시 total_score 낮은 순 (ASC)
점수 기준
keyword_evaluations의 가장 최근 평가 레코드 total_score 사용. 평균값 아님. 조건 없이 순차 삭제.

💡 설계 의도: 초반에는 evaluation_count가 낮아 1순위 후보가 거의 없음. 2순위가 안전망 역할. 시간이 쌓일수록 1순위 정책이 주로 작동하게 됨.
