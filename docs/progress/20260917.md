# 2026-09-17 진행 기록

## Agent Workforce 계약 확정

- Agent Workforce를 프로젝트 기획과 분리된 실행·추적·검증 스킬로 확정했다.
- 승인된 MODULE_SPEC을 발동 전 최소 제출물로 정의했다.
- Module Spec이 없거나 필수 항목이 부족하면 작업을 배정하지 않고 `decision_required`로 보류한다.
- 계획 계층을 `MODULE_SPEC → WORK_ORDER → TASK_BOARD.yaml`로 확정했다.
- 사람 수가 아니라 에이전트 인스턴스별로 task·Codespace·branch·PR을 분리한다.
- PR/push 감지용 M Monitor는 상태 권위자가 아니라 변화 감지기이며, M 검토 세션을 호출하는 보조 역할로 정의했다.
- `.github/workflows/agent-workforce-monitor.yml`과 이벤트 정규화기를 추가해 push·PR·review 이벤트를 artifact로 보존하고 선택적 `MONITOR_WEBHOOK_URL`로 전달하도록 연결했다.
- webhook endpoint와 저장소 secret은 아직 설정하지 않았으므로, 현재는 이벤트 캡처가 완료된 상태이며 M 자동 호출은 endpoint 설정 후 활성화된다.
