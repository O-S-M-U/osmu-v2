- 실제 시작점: 작업 직전 `agent/worker-d/0.1b-r1-version-procedure`를 최신 `origin/main`으로 fast-forward하고 관찰한 SHA를 progress에 기록한다.

## 작업 방법

1. `git fetch origin` 후 작업 branch를 `origin/main`으로 fast-forward하고, branch와 main의 SHA가 같은지 보고한다.
2. `AGENTS.md`, `.agent/project.md`, `.agent/rules.md`, 이 계약, 기준 문서와 결정 기록을 읽는다.
3. 기존 PR #4의 결론을 정답으로 전제하지 말고, 원래 `0.1B` 수용 기준에서 절차를 독립적으로 도출한다.
4. 현재 main의 결과와 비교해 누락·모호성·오류가 있으면 허용 경로 안에서 수정한다.
5. 차이가 없더라도 독립 검증 과정, 검사 결과와 근거를 progress에 남긴다.
6. commit·push·PR 후 `review` 또는 `pr`에서 멈추고 다음 작업을 self-claim하지 않는다.
